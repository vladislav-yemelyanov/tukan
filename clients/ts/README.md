# Tukan TypeScript Client (`tukan`)

Zero-dependency, schema-typed `fetch` HTTP client for OpenAPI types generated by [Tukan](https://github.com/vladislav-yemelyanov/tukan).

[![npm](https://img.shields.io/npm/v/tukan?label=npm)](https://www.npmjs.com/package/tukan)
[![Tukan CLI](https://img.shields.io/github/v/release/vladislav-yemelyanov/tukan?label=Tukan%20CLI)](https://github.com/vladislav-yemelyanov/tukan)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://github.com/vladislav-yemelyanov/tukan/blob/main/LICENSE)

- **Zero dependencies** — built purely on Web Fetch APIs (`Node >= 18`, browsers, edge runtimes).
- **End-to-end OpenAPI typing** — typed paths, methods, `path`/`query`/`headers`/`cookie` params, request bodies, success payloads, and per-status error bodies. Generated `api.ts` files stay pure compile-time types with zero runtime imports.
- **Never throws** — every request returns `{ data, error, response }` with 7 typed error categories.

## Install

```sh
npm install tukan
```

Generate your `Schemas` types first with [Tukan CLI](https://github.com/vladislav-yemelyanov/tukan#install).

## Quick start

```ts
import { createClient } from "tukan";
import type { Schemas } from "./generated/tasks";

const api = createClient<Schemas>({
  baseUrl: "https://api.example.com",
  timeoutMs: 10_000,
  headers: async () => ({
    Authorization: `Bearer ${await tokenStore.getAccessToken()}`,
  }),
});

const { data, error } = await api.path("/api/v1/tasks/{taskId}").patch({
  path: { taskId: "tsk_01" },
  body: { title: "Ship v0.4" },
});

if (error) {
  if (error.is(400) && error.body) {
    console.error(error.body.fieldErrors);
  } else {
    console.error(error.body?.message ?? error.message);
  }
} else {
  console.log(data.title);
}
```

## Error handling

Every call resolves to `ClientResult<TData, TErrorMap>`:

- **Success:** `{ data: TData; error: undefined; response: Response }`
- **Failure:** `{ data: undefined; error: ClientError<TErrorMap>; response: Response | undefined }`

All failures belong to a 7-variant discriminated union on `error.kind`:

| `kind` | Class | Trigger |
| --- | --- | --- |
| `"response"` | `ApiResponseError` | Non-2xx response with a parsed body (`error.is(status)` narrows `error.body` to that status schema). |
| `"unexpected_http"` | `UnexpectedHttpError` | Non-2xx response with malformed JSON. |
| `"network"` | `NetworkError` | Transport failure before a response arrived (offline, DNS, TLS). |
| `"timeout"` | `TimeoutError` | Request exceeded `timeoutMs`. |
| `"cancelled"` | `CancelledError` | Aborted via `AbortSignal`. |
| `"decode"` | `DecodeError` | `2xx` response with malformed JSON. |
| `"client"` | `UnexpectedClientError` | Request build error, throwing hook, or internal failure (`error.stage`). |

Handle categories exhaustively with `switch (error.kind)` or use helpers `error.is(status)`, `error.isStatus(code)`, `error.isNetworkError`, `error.isTimeout`, and `error.isCancelled`:

```ts
if (error) {
  switch (error.kind) {
    case "cancelled":
      return;
    case "network":
    case "timeout":
      return showRetryBanner();
    case "response":
      return showApiError(error.body?.message ?? error.message);
    case "decode":
    case "unexpected_http":
    case "client":
      reportError(error.cause);
      return showGenericError();
  }
}
```

## Configuration & per-call options

| Option | Description |
| --- | --- |
| `baseUrl` | Required API base URL (trailing slashes trimmed; relative prefixes like `"/proxy"` supported). |
| `headers` | Static headers or sync/async `({ method, path, url }) => HeadersInit` provider. |
| `timeoutMs` | Default timeout in ms (overridable per call). |
| `fetch` | Custom `fetch` implementation for SSR, proxies, or unit tests. |
| `requestInit` | Base `RequestInit` options (`credentials`, `cache`, `redirect`, `keepalive`). |
| `onRequest` / `onResponse` / `onError` | Single hook or array of sequential lifecycle hooks. |

Any operation accepts per-call `query`, `headers`, `cookie`, `contentType`, `timeoutMs`, `signal` (`AbortSignal`), `requestInit`, and `extra` (shallow-copied into hook context). Optional query/header/cookie fields work seamlessly with `exactOptionalPropertyTypes: true`.

Request serialization handles JSON, `FormData` / `multipart/form-data`, and `application/x-www-form-urlencoded` automatically.

## Hooks & 401 refresh

Hooks run in order: `onRequest` → `fetch` → `onResponse` (returning a `Response` replaces it) → `onError`. Exceptions inside hooks are caught as `UnexpectedClientError(stage: "hook")`.

```ts
import type { OnResponseHook } from "tukan";

const refreshOn401: OnResponseHook = async (ctx, response) => {
  if (response.status !== 401 || ctx.extra._retried) return;
  if (!(await refreshAccessToken())) return;

  ctx.extra._retried = true;
  ctx.headers.set("Authorization", `Bearer ${tokenStore.getAccessToken()}`);
  return fetch(ctx.url, { ...ctx.init, headers: ctx.headers });
};
```

## Testing

Inject a mock `fetch` directly into `createClient`:

```ts
const api = createClient<Schemas>({
  baseUrl: "https://api.example.test",
  fetch: async () =>
    new Response(JSON.stringify({ message: "Unauthorized" }), {
      status: 401,
      headers: { "Content-Type": "application/json" },
    }),
});
```
