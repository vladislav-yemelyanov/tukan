# Tukan Dart Client (`tukan`)

Zero-dependency, `dart:io`-native typed HTTP client for Dart models and `Paths` operation trees generated by [Tukan](https://github.com/vladislav-yemelyanov/tukan).

[![pub.dev](https://img.shields.io/pub/v/tukan?label=pub.dev)](https://pub.dev/packages/tukan)
[![Tukan CLI](https://img.shields.io/github/v/release/vladislav-yemelyanov/tukan?label=Tukan%20CLI)](https://github.com/vladislav-yemelyanov/tukan)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://github.com/vladislav-yemelyanov/tukan/blob/main/LICENSE)

- **Zero dependencies** — uses only the Dart standard library (`Dart >= 3.5.0`), with pluggable `HttpTransport` for Flutter Web or custom HTTP stacks.
- **Compile-time route & slot safety** — generated `Paths` typestate builders verify path params, required slots, success type `T`, and error type `E` at compile time, with zero imports of `package:tukan` in generated `api.dart`.
- **Never throws** — every call returns `Future<ApiResult<T, E>>` with a 7-subtype sealed `ApiError<E>`.

## Install

```sh
dart pub add tukan
```

Generate your Dart models and `Paths` tree first with [Tukan CLI](https://github.com/vladislav-yemelyanov/tukan#install).

## Quick start

```dart
import 'package:tukan/tukan.dart';
import '../generated/tasks.dart' as tasks;

final client = TukanClient(
  TukanClientConfig(
    baseUrl: 'https://api.example.com',
    timeout: const Duration(seconds: 10),
    headersProvider: (_) async => {
      'Authorization': 'Bearer ${await tokenStore.getAccessToken()}',
    },
  ),
);

final _tasks = tasks.Paths.api.v1.tasks;

final result = await client.send(
  _tasks.byTaskId('tsk_01').patch.body(title: 'Ship v0.4').request,
);

switch (result) {
  case ApiSuccess(:final data):
    print(data.title);
  case ApiFailure(:final error):
    print(error.body?.apiErrorResponse?.message ?? error.message);
}
```

## Generated `Paths` & builders

Tukan generates immutable typestate builders mirroring your OpenAPI paths—incomplete requests do not compile:

- **Inline path params:** `_tasks.byTaskId(id)` binds `{taskId}` directly when child operations agree on its type (otherwise `.pathParams(...)`).
- **Fluent slots:** chain `.query(...)`, `.headers(...)`, `.cookie(...)`, `.body(...)`, `.contentType(...)`, or DTO variants (`.withQuery(...)`, `.withBody(...)`).
- **Terminal `.request`:** exposed only once all required slots are filled; returns a Dart 3 structural record passed straight to `client.send(...)`.

Per-call overrides can be passed alongside `operation`:

```dart
final result = await client.send(
  _tasks.get.query(status: tasks.TaskStatus.todo).request,
  timeout: const Duration(seconds: 3),
  cancelToken: cancelToken,
  headers: const {'X-Trace': 'custom'},
);
```

## Error handling

`ApiResult<T, E>` is a `sealed class` (`ApiSuccess<T, E>` | `ApiFailure<T, E>`). Every failure is one of 7 `sealed class ApiError<E>` subtypes:

| Subtype | Trigger | `body` (`E?`) |
| --- | --- | --- |
| `ApiResponseError<E>` | Non-2xx response decoded into the operation's error type `E`. | `E` (non-null) |
| `UnexpectedHttpError<E>` | Undeclared non-2xx status, malformed error JSON, or decoder failure. | `null` (`rawBody` set) |
| `NetworkError<E>` | Transport failure before a response arrived (offline, DNS, TLS). | `null` |
| `TimeoutError<E>` | Request exceeded `timeout` or `config.timeout`. | `null` |
| `CancelledError<E>` | Aborted via `CancelToken`. | `null` |
| `DecodeError<E>` | `2xx` response failed JSON or `fromJson` decoding (backend drift). | `null` (`rawBody` set) |
| `UnexpectedClientError<E>` | Request build error, throwing hook, or internal error (`stage`). | `null` |

`E` is inferred automatically per endpoint (`Never` for no error schemas, the model directly for one, or a generated `sealed class <Op>Error` union for 2+):

```dart
switch (result) {
  case ApiSuccess(:final data):
    return data;
  case ApiFailure(error: CancelledError()):
    return null;
  case ApiFailure(error: NetworkError() || TimeoutError()):
    showRetryBanner();
  case ApiFailure(error: ApiResponseError(:final body)):
    showApiError(body);
  case ApiFailure(error: DecodeError() || UnexpectedHttpError() || UnexpectedClientError()):
    showGenericError();
}
```

## Configuration & hooks

| Option | Description |
| --- | --- |
| `baseUrl` | Required API base URL (trailing slashes trimmed). |
| `headers` / `headersProvider` | Static headers and/or sync/async per-request header callback. |
| `timeout` | Default `Duration` timeout (overridable per call). |
| `transport` | Custom `HttpTransport` (defaults to `IoHttpTransport`; required on Flutter Web). |
| `errorFromJson` / `errorDecoders` | Client-wide fallback error decoders by status code. |
| `onRequest` / `onResponse` / `onError` | Sequential lifecycle hooks (throwing hooks become `UnexpectedClientError`). |

Call `client.close()` when disposing a client that owns its default `IoHttpTransport`. Returning a `RawHttpResponse` from `onResponse` replaces the active response (useful for single-flight 401 token refresh using `context.extra`).

## Cancellation & testing

Use `CancelToken` to abort in-flight requests (immediately tearing down the underlying `dart:io` socket):

```dart
final token = CancelToken();
token.cancel('user left screen');

final result = await client.send(_tasks.get.request, cancelToken: token);
```

For fast in-memory tests or custom transports (such as Flutter Web / `package:http` / `dio`), use `HttpTransport.fromHandler`:

```dart
final client = TukanClient(
  TukanClientConfig(
    baseUrl: 'https://api.example.test',
    transport: HttpTransport.fromHandler((req) {
      return RawHttpResponse.json({'message': 'Unauthorized'}, statusCode: 401);
    }),
  ),
);
```

## Manual requests

For endpoints without generated `Paths`, `TukanClient` also provides `get<T>`, `post<T>`, `put<T>`, `patch<T>`, `delete<T>`, `head`, `options<T>`, `client.path(...)`, `ApiEndpoint<T>`, and reusable `Decoders` (`Decoders.list(...)`, `Decoders.map(...)`, `Decoders.bytes`, etc.).
